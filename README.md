# CRM Bot System

## Описание
Система управления заявками с:
- Telegram-ботом для обработки заказов
- Веб-интерфейсом для менеджеров
- Отслеживанием статусов (Новая, В работе, Доставка, Завершена)

## Установка
1. Клонировать репозиторий
2. Установить зависимости:
```bash
pip install -r requirements.txt
```
3. Настроить `.env` файл (пример в `.env.example`)

## Запуск
### Бэкенд (Flask API)
```bash
python app.py
```

### Бот (crm_bot.py)
```bash
python crm_bot.py
```

### Веб-интерфейс (Next.js)
```bash
cd frontend
npm install
npm run dev
```

## Основные компоненты
- `app.py` - Flask API (бэкенд)
- `crm_bot.py` - Telegram бот (работает через API)
- `/frontend` - Next.js приложение (фронтенд)

## Архитектура проекта
Проект реорганизован с использованием модульной архитектуры для лучшей поддерживаемости и масштабируемости:

### Структура API
```
api/
├── __init__.py         # Инициализация приложения
├── models/             # Модели данных
│   ├── __init__.py
│   └── lead.py         # Модель заявки
├── routes/             # Маршруты API
│   ├── __init__.py
│   └── lead_routes.py  # Маршруты для заявок
├── services/           # Сервисный слой (бизнес-логика)
│   ├── __init__.py
│   └── lead_service.py # Логика работы с заявками
└── utils/              # Вспомогательные функции
    ├── __init__.py
    ├── database.py     # Функции для работы с БД
    └── helpers.py      # Общие утилиты
```

### Принципы модульной архитектуры
- **Разделение ответственности**: каждый модуль отвечает за свой функционал
- **Чистота кода**: отделение бизнес-логики от маршрутов и моделей
- **Тестируемость**: модули могут быть протестированы независимо друг от друга
- **Масштабируемость**: легко добавлять новую функциональность без изменения существующего кода

### Маршруты API
- **/** - Главная страница
- **/leads** - Список всех заявок
- **/lead_details/{id}** - Детальная информация о заявке
- **/user_leads/{phone}** - Заявки пользователя по номеру телефона
- **/stats** - Статистика по заявкам
- **/reset** - Сброс базы данных (POST-запрос)

## Конфигурация
Скопировать `.env.example` в `.env` и задать:
- `TELEGRAM_TOKEN` - токен бота
- `DATABASE_URL` - строка подключения к БД
- `API_URL` - адрес API (по умолчанию `http://localhost:5000`)

## Порты по умолчанию
- Flask API: 5000
- Next.js: 3000
- Бот: зависит от конфигурации Telegram
